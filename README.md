# 酒店入住体验文案生成器

按参考视频复现的手机网页：选择满意度、体验标签和发布平台，生成并复制文案，再由用户打开对应平台 App，找到自己的订单并手动发布评价。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173/`。手机真机测试需要把页面部署到 HTTPS 地址，再用该地址生成二维码。

## 部署

三个网页文件 `index.html`、`styles.css`、`app.js` 可直接部署到 GitHub Pages、静态网站托管或自有 HTTPS 服务器。无需安装依赖、数据库或 AI 接口。

## 边界

- 网页负责生成文案、复制和尝试唤起美团／携程／飞猪 App；订单选择和评价发布由用户在平台 App 内完成。
- 微信内置浏览器可能阻止唤起外部 App，页面会提示用户在浏览器中打开。
- 文案来自本地预设语句，发布前应核对是否符合实际入住体验。
- 当前项目未部署到公网，因此尚无可供他人扫码访问的正式二维码。

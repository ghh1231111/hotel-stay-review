# 餐饮用餐体验文案生成器

手机端餐饮评价网页：选择满意度、用餐体验标签和发布平台，生成并复制文案，再由用户打开美团或大众点评，找到本次用餐的门店或订单并手动发布评价。

提供口味、食材、服务、环境、卫生、性价比、分量、上菜、摆盘、聚餐、位置和停车 12 个标签。未选择标签时使用通用用餐文案；四星评价采用较克制的措辞。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173/`。本地预览依赖电脑开机并持续运行该服务；正式网址不依赖电脑。

## 正式网页

网页已部署到 GitHub Pages：<https://ghh1231111.github.io/hotel-stay-review/>。

二维码指向上述地址。网页由 GitHub Pages 托管，访问时不需要保持个人电脑开机。项目无需安装依赖、数据库或 AI 接口。

## 边界

- 网页负责生成文案、复制和尝试唤起美团／大众点评 App；门店或订单选择和评价发布由用户在平台 App 内完成。
- 微信内置浏览器可能阻止唤起外部 App，页面会提示用户在浏览器中打开。
- 文案来自本地预设语句，发布前应核对是否符合本次实际用餐体验。
- 餐饮版的 App 唤起与平台内发布仍需在 iPhone、Android 和微信中真机验证，桌面浏览器检查不能代替这些验证。

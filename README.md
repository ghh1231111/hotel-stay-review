# 酒店入住体验文案生成器

按参考视频复现的手机网页：选择满意度、体验标签和发布平台，生成并复制文案，再点击下方对应的“打开 App”按钮尝试直接跳转；用户在 App 中找到自己的订单并手动发布评价。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173/`。本地预览依赖电脑开机并持续运行该服务；正式网址不依赖电脑。

## 正式网页

网页已部署到 GitHub Pages：<https://ghh1231111.github.io/hotel-stay-review/>。

二维码指向上述地址。网页由 GitHub Pages 托管，访问时不需要保持个人电脑开机。项目无需安装依赖、数据库或 AI 接口。

## 边界

- 网页负责生成文案、复制和尝试唤起美团／携程／飞猪 App；订单选择和评价发布由用户在平台 App 内完成。
- 微信内点击“打开 App”也会发起跳转尝试；页面不显示微信环境和跳转提示。用户的 iPhone 实测：微信内点“打开美团 App”无响应，通过右上角菜单“在浏览器打开”后点击同一按钮可打开美团。
- 也可用 iPhone 系统相机扫描同一二维码，在手机浏览器中完成网页操作。携程、飞猪及其他手机环境尚未真机验证。
- 文案来自本地预设语句，发布前应核对是否符合实际入住体验。
- 公开网页和二维码已生成；美团在用户 iPhone 手机浏览器中的唤起已有用户实测反馈，微信内直开受微信限制。
